Color System

Cor. Três camadas, uma marca.

A paleta vive em três camadas que nunca se misturam: estrutura (preto + cinzas neutros), marca (cream + orange) e sistema (semânticos calibrados). Cada token tem propósito único.

05Rules

Regras de cor.

Faça
  • Texto sobre laranja = branco puro (#FFF), sempre. Nunca preto.
  • Texto sobre creme = preto Fatax (#0A0A0A).
  • Use primary-soft para fundos suaves de badge/highlight.
  • Empilhe surfaces por contraste de cor, não por sombra.
  • Use semânticos com economia — eles são alarmes, não decoração.
Não faça
  • Não use preto puro #000 no fundo.
  • Não use gradientes na cor da marca. Sólido sempre.
  • Não use cinzas frios (#888). Tudo é warm gray.
  • Não crie um segundo acento. Existe um laranja só.
  • Não use semânticos como cor de marca (success verde ≠ marca).
