Ícones. Linguagem visual auxiliar.

O ícone substitui palavra quando o ícone é universal. Quando não é, escreva. O sistema Fatax é híbrido por design: sprite custom para navegação e conceitos recorrentes da marca, Lucide inline para tudo o mais. Mesma anatomia, dois catálogos.

03Promotion

Quando promover Lucide → sprite.

Se um ícone Lucide aparece em 3+ lugares do sistema ou representa um conceito recorrente da marca, vira <symbol> no sprite. Isso evita duplicidade de markup e centraliza a manutenção.

04Rules

Regras.

Faça
  • Use sprite custom para navegação, brand e conceitos Fatax recorrentes.
  • Use Lucide inline para UI pontual (close, plus, check, alert, etc).
  • Use ícone + label sempre que possível. Ícone solo só em ações universais.
  • Mantenha stroke consistente dentro da mesma tela.
  • Use currentColor — facilita theming e hover/active.
  • Promova ícone Lucide ao sprite quando aparecer em 3+ lugares.
Não faça
  • Não adicione uma terceira fonte (Heroicons, Material, Phosphor, Feather "oficial").
  • Não use ícones filled sólidos no UI — só stroke.
  • Não use ícones coloridos brilhantes. Cor vem do contexto.
  • Não use emoji decorativo no lugar de ícone funcional.
  • Não duplique um ícone do sprite com versão Lucide — sempre prefira o sprite quando existir.
