01Contrast

Contraste — pares aprovados.

Texto normal: 4.5:1. Texto grande/bold: 3:1. Componentes não-textuais: 3:1.

02Focus

Foco visível.

Foco de teclado nunca some. Padrão: ring laranja 2px + offset 2px.

:focus-visible {
  outline: 2px solid var(--brand-orange);
  outline-offset: 2px;
  border-radius: var(--r-sm);
}
03Motion

Motion-safe.

Respeitar prefers-reduced-motion. Movimento decorativo é cortado; movimento essencial (transições de estado) cai pra 0.01ms.

@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    transition-duration: 0.01ms !important;
    scroll-behavior: auto !important;
  }
}
